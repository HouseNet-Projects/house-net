# Enforcement map

## English

The HouseNet control-plane reusable gate enforces registration, Class B requirements, bilingual human-facing files, workflow permissions, action pinning and repository metadata. This repository's validator enforces token schemas, references, logo provenance, internal links and source-template consistency. Human review remains responsible for visual quality, translation equivalence and accessibility judgment.

## Հայերեն

HouseNet control-plane-ի reusable gate-ը enforced է պահոցի registration-ի, Class B պահանջների, bilingual human-facing ֆայլերի, workflow permissions-ի, action pinning-ի և metadata-ի համար։ Այս պահոցի validator-ը enforced է token schema-ների, reference-ների, logo provenance-ի, internal links-ի և source-template consistency-ի համար։ Visual quality-ի, թարգմանության համարժեքության և accessibility-ի դատողությունը մնում է մարդու review-ի պատասխանատվությունը։
