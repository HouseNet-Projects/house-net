# Usage guide

## English

Start with the control-plane lock, then import the token files. Use semantic token names such as `color.primary` and `space.4`; do not paste raw colors into product code. For a document, choose a registered type, copy its source definition, keep EN/HY sections together, and run both validators before delivery.

## Հայերեն

Սկսեք control-plane lock-ից, ապա բեռնեք token ֆայլերը։ Օգտագործեք semantic token անուններ, օրինակ՝ `color.primary` և `space.4`, և raw գույները մի տեղադրեք product code-ում։ Փաստաթղթի համար ընտրեք գրանցված տեսակ, պատճենեք source definition-ը, EN/HY բաժինները պահեք միասին և delivery-ից առաջ գործարկեք երկու validator-ները։
