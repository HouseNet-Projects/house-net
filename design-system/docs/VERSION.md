# Versioning

## English

The design system is `1.1.0` after the product-grade visual language release. Use semantic versioning for token or template contract changes. A patch fixes documentation or a non-breaking example; a minor version adds compatible tokens/components; a major version removes or renames a public token. Releases are created only when they help consumers reproduce a stable source.

## Հայերեն

Դիզայնի համակարգը այժմ `1.1.0` տարբերակն է՝ product-grade visual language release-ից հետո։ Token-ի կամ template contract-ի փոփոխությունների համար օգտագործեք semantic versioning։ Patch-ը ուղղում է documentation-ը կամ non-breaking example-ը, minor-ը ավելացնում է համատեղելի token/component, major-ը հեռացնում կամ վերանվանում է public token։ Release ստեղծեք միայն այն դեպքում, երբ այն օգնում է սպառողներին վերարտադրել կայուն source։
