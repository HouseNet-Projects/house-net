# Document System

## English

Documents are a first-class design-system surface. This subsystem defines reproducible source standards for Word, PowerPoint, Excel and PDF delivery without requiring one frontend framework or a proprietary binary editor.

| Type | Source standard | Required structure |
| :--- | :--- | :--- |
| Policy | `documents/policy/` | Purpose, scope, authority, rules, exceptions, enforcement, version history |
| SOP / Procedure | `documents/procedure/` | Purpose, preconditions, roles, steps, exceptions, escalation, verification |
| Report | `documents/report/` | Executive summary, findings, metrics, risks, actions/decisions |
| Proposal | `documents/proposal/` | Context, solution, scope, resources/cost, risks, decision required |
| Memo | `documents/memo/` | Context, decision/message, facts, action |
| Operational review | `documents/operational-review/` | Scorecard, variance, risks, updates, decisions, actions |

Human-facing source and templates must include complete English and Armenian sections. PDFs are delivery outputs: preserve selectable text, metadata, page size, print margins, logo quality and bilingual reading order.

## Հայերեն

Փաստաթղթերը design system-ի առաջին կարգի մակերես են։ Այս subsystem-ը սահմանում է Word-ի, PowerPoint-ի, Excel-ի և PDF-ի վերարտադրելի source standards՝ առանց մեկ frontend framework-ի կամ փակ binary editor-ի պարտադրանքի։

| Տեսակ | Source standard | Պարտադիր կառուցվածք |
| :--- | :--- | :--- |
| Policy | `documents/policy/` | Նպատակ, scope, authority, կանոններ, exceptions, enforcement, version history |
| SOP / Procedure | `documents/procedure/` | Նպատակ, preconditions, դերեր, քայլեր, exceptions, escalation, verification |
| Report | `documents/report/` | Executive summary, findings, metrics, risks, actions/decisions |
| Proposal | `documents/proposal/` | Context, solution, scope, resources/cost, risks, decision required |
| Memo | `documents/memo/` | Context, decision/message, facts, action |
| Operational review | `documents/operational-review/` | Scorecard, variance, risks, updates, decisions, actions |

Մարդկանց համար նախատեսված source-ը և templates-ը պետք է ունենան ամբողջական English և Հայերեն բաժիններ։ PDF-ը delivery output է․ պահպանեք selectable text-ը, metadata-ն, page size-ը, print margins-ը, logo quality-ն և երկլեզու ընթերցման հերթականությունը։
