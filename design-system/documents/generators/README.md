# Reproducible document sources

## English

Canonical document sources live beside their type definitions. A future generator may turn these Markdown/JSON sources into `.docx`, `.pptx`, `.xlsx` or PDF delivery files. Generated binaries must retain the source path, design-system version and control-plane version in their metadata. The repository does not treat opaque binaries as the authority.

## Հայերեն

Կանոնական document source-ները պահվում են իրենց type definition-ների կողքին։ Ապագա generator-ը կարող է այս Markdown/JSON source-ներից ստեղծել `.docx`, `.pptx`, `.xlsx` կամ PDF delivery files։ Ստեղծված binary-ները metadata-ում պետք է պահեն source path-ը, design-system version-ը և control-plane version-ը։ Opaque binary-ը այս repository-ում authority չէ։
