# Operational review sources

## English

Operational reviews present a scorecard, variance, risks, functional updates, decisions and actions. Use status tokens with text labels.

## Հայերեն

Operational review-ները ներկայացնում են scorecard, variance, risks, functional updates, decisions և actions։ Status token-ները օգտագործեք տեքստային label-ների հետ։
