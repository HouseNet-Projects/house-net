# Proposal sources

## English

Proposal sources explain context, solution, scope, resources/cost, risks and the decision required. Keep assumptions explicit.

## Հայերեն

Proposal source-ները բացատրում են context-ը, solution-ը, scope-ը, resources/cost-ը, risks-ը և պահանջվող decision-ը։ Ենթադրությունները պահեք բացահայտ։
