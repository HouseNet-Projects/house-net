# HouseNet enforcement hardening / HouseNet-ի enforcement hardening

## English

This evidence package records executable enforcement for the current five-repository HouseNet estate at policy `1.4.2`. It separates policy authority from domain validators, runtime gates, cross-repository checks and GitHub provider protection. `evidence-matrix.json` is the machine-readable record; it does not replace any policy owner.

All canonical `main` branches have strict required checks, administrator enforcement, force-push protection and deletion protection. Knowledge and Vault received the missing provider-level protection during this pass. The remaining `PARTIALLY ENFORCED` rows are explicit limits: human owner decisions, GitHub sequencing limits, or human semantic review.

## Հայերեն

Այս evidence package-ը գրանցում է HouseNet-ի ընթացիկ հինգ repository-ների executable enforcement-ը՝ policy `1.4.2`-ի համար։ Այն տարանջատում է policy authority-ն, domain validator-ները, runtime gate-երը, cross-repository ստուգումները և GitHub-ի provider protection-ը։ `evidence-matrix.json`-ը machine-readable գրանցում է և չի փոխարինում որևէ policy owner-ի։

Բոլոր canonical `main` branch-երը ունեն strict required checks, administrator enforcement, force-push-ի և deletion-ի արգելք։ Այս փուլում Knowledge և Vault repository-ների բացակայող provider-level protection-ը լրացվել է։ `PARTIALLY ENFORCED` տողերը դիտավորյալ սահմանափակումներ են՝ owner decision, GitHub sequencing-ի սահմանափակում կամ մարդկային semantic review։
