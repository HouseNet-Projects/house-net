# Accessibility baseline

## English

All product implementations should target WCAG 2.2 AA where applicable: keyboard access, visible focus, semantic landmarks, labels, error recovery, sufficient contrast, reduced-motion respect, and non-color status communication. Review generated artifacts with a human; the token validator cannot prove accessibility.

## Հայերեն

Բոլոր արտադրանքների իրականացումները, երբ կիրառելի է, պետք է նպատակադրեն WCAG 2.2 AA՝ keyboard access, տեսանելի focus, semantic landmarks, labels, error recovery, բավարար contrast, reduced-motion հարգում և գույնից անկախ status հաղորդակցում։ Ստեղծված նյութերը ստուգեք մարդու կողմից․ token validator-ը չի կարող ապացուցել accessibility-ը։
