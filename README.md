# HouseNet

Canonical HouseNet monorepo containing the governed Control Plane, Design System, Command Center / Deputy runtime, Knowledge and Vault components.

HouseNet-ի կանոնական մոնոռեպոն, որը ներառում է կառավարվող Control Plane, Design System, Command Center / Deputy runtime, Knowledge և Vault բաղադրիչները։

Component ownership remains explicit: governance in `control-plane/`, brand and templates in `design-system/`, Deputy and operational state in `command-center/`, durable knowledge in `knowledge/`, and secret-reference metadata in `vault/`.
