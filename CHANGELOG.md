# Changelog

## English

### 1.1.0 — 2026-09-15

Added mandatory bilingual English + Armenian coverage for human-facing HouseNet content, with deterministic document markers and repository-gate validation. The official HouseNet visual system is retained and presented with first-party logo provenance.

## Հայերեն

### 1.1.0 — 15.09.2026

Մարդկանց համար նախատեսված HouseNet-ի նյութերի համար ավելացվել է անգլերեն և հայերեն ամբողջական բովանդակության պարտադիր պահանջը՝ փաստաթղթերի հստակ նշիչներով և պահոցի ստուգման կանոնով։ Պահպանվել է HouseNet-ի պաշտոնական տեսողական համակարգը՝ առաջին կողմի լոգոյի աղբյուրի գրանցմամբ։

### 1.0.0 — 2026-09-15

Initial owner-authorized engineering control plane: machine policy, source coverage, classification registry, deterministic validators, agent maps, private reusable gate and original light/dark visual system.

## 1.0.0 — 15.09.2026

Սկզբնական, սեփականատիրոջ կողմից հաստատված ինժեներական կառավարման հարթակ՝ մեքենայական քաղաքականությամբ, աղբյուրի ծածկույթով, դասակարգման ռեեստրով, որոշակի ստուգիչներով, գործակալների քարտեզներով և մասնավոր վերօգտագործվող դարպասով։
