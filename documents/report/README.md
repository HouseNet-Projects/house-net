# Report sources

## English

Report sources use executive summary, findings, metrics, risks and actions/decisions. Charts must identify source, unit, period and comparison.

## Հայերեն

Report source-ները օգտագործում են executive summary, findings, metrics, risks և actions/decisions։ Charts-ը պետք է նշեն աղբյուրը, միավորը, ժամանակահատվածը և համեմատությունը։
