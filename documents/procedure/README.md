# Procedure sources

## English

Procedure sources define preconditions, roles, steps, exceptions, escalation and verification. Keep operational steps testable and bilingual.

## Հայերեն

Procedure source-ը սահմանում է preconditions, դերերը, քայլերը, exceptions, escalation-ը և verification-ը։ Գործառնական քայլերը պահեք ստուգելի և երկլեզու։
