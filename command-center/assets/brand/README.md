# HouseNet Command Center brand asset

## English

`housenet-footer-logo.svg` is an unchanged presentation copy of the official HouseNet footer logo. The canonical brand authority remains [`HouseNet-Projects/house-net-design-system`](https://github.com/HouseNet-Projects/house-net-design-system). It is used here only to keep the Command Center landing surface self-contained and offline-readable.

## Հայերեն

`housenet-footer-logo.svg`-ը HouseNet-ի պաշտոնական footer logo-ի անփոփոխ presentation copy-ն է։ Կանոնական brand authority-ը մնում է [`HouseNet-Projects/house-net-design-system`](https://github.com/HouseNet-Projects/house-net-design-system)։ Այն այստեղ օգտագործվում է միայն Command Center-ի landing surface-ը ինքնաբավ և offline-ընթեռնելի պահելու համար։
