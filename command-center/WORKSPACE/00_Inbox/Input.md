# 00_Inbox / Input.md — մուտքի սեղան

Այս պանակը (00_Inbox) քո **մուտքի սեղանն է**. ամեն ֆայլ, սքրինշոթ, export, docx, xlsx՝ գցի այստեղ, անուն/կարգ չմտածելով։ Deputy-ն ամեն սեսիա բացելիս տանում է ճիշտ տեղը (01_Active/…, 02_Reference/…, 04_Sources/…), վերանվանում ըստ ստանդարտի (`Name-vN.N-YYYY-MM-DD.ext`), գրանցում [Journal.md](../Journal.md)-ում։ Պանակը միշտ դատարկ է մնում, բացի այս ֆայլից։ Երկիմաստը՝ հարցնում է։

Ստորև՝ **հում տեքստի** տեղը (WhatsApp, նամակ, նոթ)։ Կպցրու «Չմշակված»-ի տակ. Deputy-ն դարձնում է առաջադրանք [Tasks.xlsx](../Tasks.xlsx)-ում և մաքրում մշակվածը։
