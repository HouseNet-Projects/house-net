# 04_WhatsApp — առաջադրանքների կառավարում

## Ինչու է սա գոյություն ունի

WhatsApp-ով եկած առաջադրանքը մնում է հաղորդագրության մեջ, վերև է գնում ու կորչում։
Այստեղ այն դառնում է **գրանցված քարտ՝ ամսաթվով, հեղինակով, ժամկետով, լուծումով և հաջորդ քայլով**։

## Ինչ կա այստեղ

| Ֆայլ | Ինչի համար |
|:---|:---|
| [ԱՌԱՋԱԴՐԱՆՔՆԵՐ.xlsx](ԱՌԱՋԱԴՐԱՆՔՆԵՐ.xlsx) | Ռեեստրը՝ 8 թերթ։ Տես ներքևում։ |
| [ՄՈՒՏՔ.md](ՄՈՒՏՔ.md) | Հում տեքստը։ Կպցնում ես ու մոռանում։ |
| [Բնօրինակներ/](Բնօրինակներ/) | Export-ներ, սքրինշոթներ՝ ամսաթվով պանակներում։ |
| [գործիքներ/](գործիքներ/) | Կառուցող սցենարները։ Ձեռք տալու կարիք չկա։ |

## Excel-ի 8 թերթը

| Թերթ | Ինչ է |
|:---|:---|
| **ԱՄՓՈՓ** | Օրվա պատկերը՝ 8 ցուցիչ, երկու սիմետրիկ վահանակ (այսօր / վաղը), ներքևում՝ ում ես սպասում։ Թվերը բանաձևեր են՝ ապրող։ |
| **ՕՐՎԱ ՊԼԱՆ** | Այսօրվա ցուցակը՝ ☐ նշատուփերով, համարակալված, տպելու համար պատրաստ։ |
| **ՔԱՐՏԵՐ** | Գլխավոր տեսքը։ Ամեն առաջադրանք՝ քարտ, խմբավորված ըստ հրատապության։ Նախ՝ ՍՏԱՑՎԱԾ, հետո՝ ՏՐՎԱԾ։ |
| **ՍՏԱՑՎԱԾ** | Ինձ տրված առաջադրանքները՝ 18 սյունակ, ֆիլտրով։ |
| **ՏՐՎԱԾ** | Իմ հանձնարարականները՝ ում, երբ ստուգել, ինչ է ստացվել։ |
| **ԳՐԱՆՑԱՄԱՏՅԱՆ** | Ինչ երբ արվեց՝ ժամանակագրական։ |
| **ԱՆՁԻՆՔ** | Ով ով է, որ ալիքով, քանի բաց հանձնարարական ունի։ |
| **ՀԱՐՑԵՐ** | Այն, ինչի պատասխանը չունեմ։ Կարմիրով՝ բացերը։ |

### Քարտի կարդալը

```
▌ T-2026-09-08-03   ԸՆԹԱՑՔՈՒՄ            ԱՅՍՕՐ · 09-09
▌ Մագայի գործառույթների մանրամասն նկարագիրը
▌ Ումից՝ Gadukyan · 09-08 18:50 · WhatsApp · պատասխանատու՝ Մագա → Ես · Բարձր
▌ «Մագայից … իրա գործառույթները ասա թող ուղարկի …»
▌ Լուծում՝ Առաջին տարբերակը ստացվել է, բայց մակերեսային է
▌ →  Պահանջել քայլ առ քայլ նկարագիր և առաջին 10 ավտոմատացվող կետը
▌ Կախված է՝ —   ·   Bitrix24՝ —   ·   reconciliation-ի նախապայմանն է
```

Յոթ տող՝ միշտ նույն հերթականությամբ, բոլոր քարտերում։

Ձախ գունավոր շերտը՝ **առաջնահերթությունը** (կարմիր՝ բարձր, նարնջագույն՝ միջին, մոխրագույն՝ ցածր)։
Ներքևի կապույտ տողը միշտ **հաջորդ քայլն է** — ինչ է կոնկրետ արվելու։

## Հոսքը

```
WhatsApp  →  ՄՈՒՏՔ.md կամ չատում ինձ  →  [ես]  →  ԱՌԱՋԱԴՐԱՆՔՆԵՐ.xlsx
```

1. **Դու** — WhatsApp Desktop-ում նշում ես հաղորդագրությունները, Ctrl+C, գցում ՄՈՒՏՔ.md։ Կամ ուղղակի կպցնում ես ինձ չատում։ Export-ի zip-ն էլ է աշխատում՝ գցի ֆոլդըրը։
2. **Ես** — հանում եմ առաջադրանքը, տալիս ID, լրացնում լուծումն ու հաջորդ քայլը, վերակառուցում քարտերը։
3. **Ես, ամեն սեսիա բացելիս** — ՄՈՒՏՔ + ժամկետանց + այսօրվա կետերը, առաջին բանը։

## ⚠ Կարևոր՝ որտեղ է ապրում ճշմարտությունը

Excel-ը **կառուցվում է** [գործիքներ/տվյալներ.py](գործիքներ/տվյալներ.py)-ից։ Այսինքն՝

- Եթե դու Excel-ում ձեռքով փոխես մի բան, **հաջորդ վերակառուցումը այն կջնջի**։
- Ուստի՝ փոփոխությունը ասա ինձ, ես գրում եմ տվյալների մեջ ու վերակառուցում։ Այդպես Excel-ն ու տվյալները միշտ նույնն են։
- Եթե ուզում ես ինքդ խմբագրել Excel-ում՝ ասա, ու ես այդ օրը չեմ վերակառուցի, փոխարենը կկարդամ քո գրածը։

Վերակառուցում՝ կրկնակի սեղմիր **[ԹԱՐՄԱՑՆԵԼ.bat](../ԹԱՐՄԱՑՆԵԼ.bat)**-ը (ֆոլդըրի արմատում)։
Ամսաթիվը ինքնաշխատ վերցվում է համակարգից — ձեռքով ոչինչ չի փոխվում։

## Կանոններ

- **Բնօրինակ տեքստը միշտ պահվում է։** Իմ ձևակերպումը մեկնաբանություն է, բնօրինակը՝ ապացույց։
- **ID** — ստացված՝ `T-ՏՏՏՏ-ԱԱ-ՕՕ-NN`, տրված՝ `H-ՏՏՏՏ-ԱԱ-ՕՕ-NN`։ Երբեք չի փոխվում։
- **Կարգավիճակ** — Նոր · Ընթացքում · Սպասում · Կատարված · Չեղարկված։
- **Ոչինչ չի ջնջվում։** Չեղարկվածը մնում է իր կարգավիճակով։

## Ինչ ես չեմ կարող

WhatsApp-ը ուղիղ կարդալ չեմ կարող — տվյալները գաղտնագրված են, ու ես ֆոնային պրոցես չեմ։
Ձայնային հաղորդագրություններն ու փաստաթղթերը export-ում `<voice message omitted>` են՝ դրանց մեջ եղած առաջադրանքները ինձ չեն հասնում։ Եթե ձայնայինով կարևոր բան է ասվել՝ ասա, կգրանցեմ։
